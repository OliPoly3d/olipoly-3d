# Request, quote and all-work queue update

November 4, 2026. This addresses the missing front end of the pilot: work can begin as an idea or conversation and remain visible before it is an accepted order.

## Try this first

1. On **All work**, choose **New request**. Enter a fictional customer, project, source, contact and description. Initial quantity can be revised later. No CAD, price, grams or print hours are required.
2. **Save new request** leaves it in **New request**, unpriced. Open it later and use **Save & start quote**.
3. In **Quote builder**, enter one or more items, quantities, selling prices, known material/hour estimates and a separate fixed design charge. Review estimated production cost and profit, payment terms, delivery text and quote validity. Incomplete design/slicing inputs mean incomplete cost estimates; the current pilot price is final fixed.
4. Open **Customer quote**. Review the document. Use **Print / Save quote PDF** or **Copy quote message**; send it yourself. No message is sent automatically.
5. Choose **Mark quote sent** and record the channel. It moves to **Awaiting approval** without creating an accepted order or reserving material.
6. If it changes, **Start quote revision** with a reason, edit and reshare. Prior sent amounts/history remain recorded.
7. On authorization, **Record approval & create order**. It appears in **Quote approved**, with the accepted snapshot locked. Quick work may be directly approved without a separate sent step.
8. **Release to production** reserves material; subsequent printer runs, inspection, pickup, payment and receipt use the existing workflow.

The queue shows every stage, searchable across customers/projects/references/contacts/request notes. Completed work is hidden from All open and remains available through Completed/Everything. It is one continuous work record, not separate duplicate sales for individual print runs.

## Validation

36 focused checks passed, including SQL rehearsal of saving intake, quote sends/revisions, reload and later approval through the unchanged deployed RPC interface. Unapproved work creates no Order and reserves no stock. Existing printing/reprint/payment/Finance, transport, isolation and canonical pricing checks remain passing.

Local browser QA covered intake without pricing/CAD, quote preparation with a separate design fee, customer preview, Mark quote sent, and simultaneous New request / Preparing quote / Awaiting approval rows. The preview table has quantity, unit price and amount columns. 390px and 820px iframe checks showed no horizontal document overflow. Actual iPad Safari printing and the signed-in hosted journey still need a device walkthrough.

The user's prior test records are not reset. No new migrations, Auth changes, live database changes, PR merge or customer-site deployment are included. Quote send/revision metadata uses the existing owner-scoped workspace/job payload; the baseline canonical Quote row is generated by the established approval path. Public web quote acceptance, capped design charges, automatic Finance cost reconciliation and verified tax sourcing remain later steps.
